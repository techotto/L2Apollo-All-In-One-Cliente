L2 APOLLO - L2Apollo ? All-In-One - Pacote do Cliente
=============================================

COMO OBTER / ATUALIZAR
- Clone: git clone https://github.com/techotto/L2Apollo-All-In-One-Cliente.git
- Atualizar: so dar dois cliques em atualizar.bat
- O bat baixa a versao nova e PRESERVA sua pasta config\
- config\ e local; defaults do pacote ficam em config.default\
- Se veio em ZIP: baixe o ZIP novo e substitua a pasta (faca backup do config\)

COMO INSTALAR
1. Extraia/clone esta pasta em qualquer lugar (ex: Documentos\L2Apollo-Cliente)
2. Rode L2Apollo.exe (ou mostrar-hwid.bat) e anote o HWID
3. Envie ao suporte: seu HWID (4 caracteres hex)
4. Receba sua KEY e rode instalar.bat (ou INSTALAR LICENCA no .exe)
5. Inicie o Guard (bandeja / start_guard.bat)
6. No Adrenaline, abra o .enc DESTA pasta e rode (F9)

IMPORTANTE - BaseDir
- O Guard grava o path do pacote em C:\Users\Public\l2apollo.path
- Sem Guard ativo o script pode nao achar as configs
- Alternativa: copie o pacote para
  C:\Users\Public\L2Apollo\L2Apollo-All-In-One\

COMO USAR
- Abra L2Apollo.exe para o painel de controle (se incluido)
- OU use start_guard.bat para iniciar o Guard direto
- O script L2Apollo-All-In-One.enc roda no Adrenaline
- O Guard precisa estar ativo (bandeja do Windows)

CONFIGURACAO
- Edite os arquivos .ini na pasta config\ conforme necessario
- config\ e sua (local). Defaults do pacote: config.default\
- Ao atualizar, seus INIs NAO sao sobrescritos

COMO DESINSTALAR
- Rode desinstalar.bat

IMPORTANTE
- Nao altere a pasta runtime
- Sem KEY valida o script nao funciona
- Nao compartilhe sua KEY
