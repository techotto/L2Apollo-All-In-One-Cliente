L2 APOLLO - L2Apollo ? All-In-One - Pacote do Cliente
=============================================

MAQUINA NOVA (Git + Python + clone)
- Pasta Setup-Cliente\ (setup-maquina.bat) - rode como Admin
- Instala Git, Python 3, clona o GitHub e pip do BotApollo
- Destino padrao: Documentos\L2Apollo-All-In-One-Cliente

COMO OBTER / ATUALIZAR
- Clone: git clone https://github.com/techotto/L2Apollo-All-In-One-Cliente.git
- Atualizar: SO atualizar.bat (dois cliques). NAO use git pull
- O bat detecta quem trava .enc/DLL, mata o processo e sobrescreve o pacote
- PRESERVA config\ + keys/token/helper
- Mostra SUCESSO ou FALHOU no final (commit, tamanho do .enc)
- config\ e local; defaults do pacote ficam em config.default\
- BotApollo\config.conf SOBE no git e SOBRESCREVE no update
- Se veio em ZIP: baixe o ZIP novo e substitua a pasta (faca backup do config\)

COMO INSTALAR
1. Extraia/clone esta pasta em qualquer lugar (ex: Documentos\L2Apollo-Cliente)
2. Rode atualizar.bat uma vez (grava a pasta do pacote para o script)
3. No Adrenaline, abra o .enc DESTA pasta e rode (F9)
4. No painel, preencha o CADASTRO (nome, e-mail, WhatsApp; KEY se ja tiver)
5. Aguarde o suporte liberar - o script libera sozinho

IMPORTANTE - BaseDir
- O Guard grava o path do pacote em C:\Users\Public\l2apollo.path
- Sem Guard ativo o script pode nao achar as configs
- Alternativa: copie o pacote para
  C:\Users\Public\L2Apollo\L2Apollo-All-In-One\

COMO USAR
- O script L2Apollo-All-In-One.enc roda no Adrenaline e abre o painel sozinho
- O Guard precisa estar ativo (bandeja do Windows)

CONFIGURACAO
- Edite os arquivos .ini na pasta config\ conforme necessario
- config\ e sua (local). Defaults do pacote: config.default\
- Ao atualizar, seus INIs NAO sao sobrescritos
- Ao atualizar, BotApollo\config.conf E sobrescrito (vem do GitHub)

COMO DESINSTALAR
- Rode desinstalar.bat

IMPORTANTE
- Nao altere a pasta runtime
- Sem KEY valida o script nao funciona
- Nao compartilhe sua KEY
